# Si Pintar - Toddler Learning App (fondasi)
Jalankan dengan server lokal (PWA butuh http/https), misalnya:
    python3 -m http.server 8080
lalu buka http://localhost:8080 dan pilih "Tambahkan ke layar utama" di Chrome Android.

Tambah fitur baru: salin salah satu file di /pages, ganti isi <main>, dan tambahkan
halamannya ke FILE_INTI di sw.js (naikkan VERSI).

Versi tanpa folder: semua file di satu tingkat agar mudah diunggah dari tablet.
